## Known Risks and Mitigations: <br>
Risk: API keys may be exposed if examples are copied into browser code or committed directly. <br>
Mitigation: Use environment variables or a backend proxy and avoid hard-coding credentials. <br>
Risk: Uploaded files may be sent to an external AI service or made public when public upload options are used. <br>
Mitigation: Upload only files approved for that service and use public upload settings only for files meant to be shareable. <br>
Risk: The intended SDK package and provider are not proven by server-resolved provenance. <br>
Mitigation: Confirm the package and provider from trusted channels before installing dependencies or running generated examples. <br>
