# 藏地风俗与生态保护规约

> 这是"Allen扎西"的文化守门人知识库。介绍任何神山圣湖、寺庙或藏地文化场所时,必须附带对应的底线规则。

---

## 【一】神山圣湖生态底线

### 羊卓雍措（羊湖）

| 项目 | 内容 |
|------|------|
| 海拔 | 4,441 米 |
| 位置 | 山南市浪卡子县,距拉萨约100公里 |

**必须遵守的规则：**

1. **严禁下水**：羊湖是藏民心中的"碧玉女神",禁止在湖中游泳、洗脚、洗车或任何形式接触湖水。藏民认为圣湖之水会净化人心,但人不可亵渎圣湖。
2. **禁止向湖中丢弃任何物品**：硬币、哈达、垃圾等都不可以。湖边有专门的"煨桑"台和经幡处,祈福应使用传统方式。
3. **不触碰玛尼堆**：湖边的玛尼堆是藏民一块一块垒上去的祈福石堆,每一块石头都承载着一个祈愿。严禁踢倒、取走或添加非传统石块。
4. **拍摄方向注意**：拍摄羊湖时,不要将镜头对准天葬台方向(岗巴拉山口附近有指示)。
5. **转湖方向**：如果沿湖徒步或驾车,应顺时针方向绕行。
6. **垃圾带走**：羊湖观景台和湖边没有商业垃圾桶,所有随身垃圾全部带回车上或到县城处理。

### 纳木错

| 项目 | 内容 |
|------|------|
| 海拔 | 4,718 米 |
| 位置 | 当雄县与班戈县交界处,拉萨以北约200公里 |

**必须遵守的规则：**

1. **严禁在湖中沐浴、洗涤**：常有游客想"圣湖洗尘",此为大忌。藏民长途朝圣到纳木错,也只是绕湖、磕长头、煨桑,绝不入水。
2. **转湖方向**：必须顺时针绕行。传统大转湖路线约280公里,一般信众耗时7-15天,游客通常只走扎西半岛段——但仍需顺时针。
3. **不拾取牛骨、羊角**：湖边散落的动物骨骼是自然循环的一部分,也是藏民眼中"生命轮回"的见证。不要当纪念品带走。
4. **玛尼堆与经幡**：扎西半岛有大量玛尼堆和经幡阵,可以绕行祈福,但严禁踩踏、攀爬、取走石块。
5. **海拔警告**：4718米的高海拔导致含氧量仅为平原的50%,请确认身体适应后再前往,不要在湖边过夜(湖边帐篷条件极差且危险)。
6. **禁止无人机飞行**：纳木错区域属于敏感地带,湖面和扎西半岛均禁止未经报备的无人机飞行。

### 冈仁波齐

| 项目 | 内容 |
|------|------|
| 海拔 | 6,638 米(峰顶,不攀登)/ 转山路最高处 5,630 米(卓玛拉垭口) |
| 位置 | 阿里地区普兰县 |

**必须遵守的规则：**

1. **严禁攀登**：冈仁波齐是藏传佛教、印度教、耆那教和苯教四大宗教共同尊奉的神山,至今无人登顶(也永远不应登顶)。任何攀登企图都是对藏民信仰的极大冒犯。
2. **转山方向**：
   - 藏传佛教徒：**顺时针**转山
   - 苯教徒：**逆时针**转山
   - 游客跟随大多数即可,顺时针为通用方向
3. **转山全程禁忌**：
   - 不踩踏路边的玛尼堆和经幡
   - 不在神山附近大声喧哗(藏民认为会惊扰山神)
   - 不在转山路上遗留任何垃圾,所有废弃物随身携带出山
   - 不在神山附近杀生(包括钓鱼、捕鸟)
4. **物理准备**：转山全程约52公里,最高点卓玛拉垭口5630米,需2-3天。阿里地区平均海拔4500米以上,进藏不满10天者不建议前往。
5. **边防证要求**：阿里全境需要边防证,出发前务必在户籍所在地或拉萨办理。

### 通用神山圣湖守则（适用于所有藏地山水）

1. **单指指山是大忌**：介绍神山时应掌心向上、五指并拢做"请"的手势,严禁用一个手指指向神山。
2. **不带走一石一木**：藏民信仰"万物有灵",神山圣湖的一草一木一石都是神圣的。不要带走任何"纪念品"。
3. **不在水源地洗脏物**：包括溪流、泉眼、湖泊。藏民饮用的水直接来自这些水源。
4. **煨桑台不是垃圾桶**：白色桑烟是祈福用的(柏枝、糌粑、酥油),不要把塑料、包装袋等丢进去烧。
5. **经幡不能踩**：掉在地上的经幡要捡起来挂高,不能踩过去。经过经幡阵时,从下方弯腰穿过是一种尊重的表现。

## 【二】寺庙与宗教礼仪

### 大昭寺

| 项目 | 内容 |
|------|------|
| 位置 | 拉萨市城关区八廓街中心 |
| 供奉 | 释迦牟尼12岁等身像(觉沃佛) |
| 地位 | 藏传佛教最神圣的寺庙 |

**入寺禁忌：**

1. **着装要求**：
   - 严禁穿短裤、短裙、无袖上衣入内
   - 进入大殿必须脱帽、摘墨镜
   - 女性建议穿长裤或长裙,肩膀需遮盖
   - 门口有免费围裙提供,但不保证尺码齐全

2. **参拜路线**：严格顺时针绕行,从正门进入后沿左向右绕觉沃佛殿行走,不可逆行。

3. **摄影摄像禁令**：
   - 大殿内（觉沃佛殿）**绝对禁止拍照、录像**
   - 天井和外围廊道可以拍照,但不要拍僧人和磕长头的信众
   - 禁止使用闪光灯(对古老的壁画和唐卡造成不可逆损伤)

4. **行为规范**：
   - 单指指佛像：**大忌**。需要指示佛像时,应五指并拢、掌心向上做"请"的手势
   - 不可以手指触碰佛像、佛龛的玻璃
   - 拜佛时,不要站在拜垫正前方挡到他人磕头
   - 僧人诵经时保持安静,不围观、不交谈

5. **布施与供奉**：
   - 可以换零钱做布施(寺内有换钱处),建议使用纸币,不使用硬币(传统上藏区不使用硬币供奉)
   - 布施金额随心,不在多少,在于发心

### 布达拉宫

| 项目 | 内容 |
|------|------|
| 位置 | 拉萨市城关区红山 |
| 海拔 | 3,750 米(入殿需爬高约100米) |

**入寺禁忌：**

1. **着装与安检**：同大昭寺。有严格安检,打火机、刀具等不可带入。
2. **摄影禁令**：
   - 白宫和红宫内部**全面禁止拍照**,包括手机拍摄
   - 外墙和广场可以拍照
   - 进入任一殿门后有"禁止拍照"标志,必须遵守
3. **参观路线**：单向顺时针路线,不可逆行、不可停留过久堵塞通道。布达拉宫参观有严格的时间限制(一般45分钟到1小时)。
4. **戴帽子与墨镜**：进入任何佛殿之前请摘下帽子和墨镜。布达拉宫的每个殿门口有专门的"脱帽处"提示。
5. **声音控制**：布达拉宫内部木质结构为主,脚步声和说话声都会回响,请保持安静。
6. **高反提醒**：布达拉宫需要爬约300级台阶(相当于13层楼),海拔从3650米上升到3750米。建议进藏第2天后再前往。
7. **预约制度**：布达拉宫实行严格的预约制,旺季(5-10月)需提前1-7天在官方小程序预约。没有预约到了门口是进不去的。

### 扎什伦布寺（日喀则）

| 项目 | 内容 |
|------|------|
| 位置 | 日喀则市桑珠孜区 |
| 地位 | 班禅驻锡地,藏传佛教格鲁派六大寺之一 |

**禁忌要点：**
- 同大昭寺着装和参拜规则
- 弥勒佛大殿内禁拍
- 晒佛台(高32米的墙体)可以拍照,但不攀爬
- 寺内有辩经场,可以在场外观摩,但不干扰辩经

### 通用寺庙守则（适用于所有藏传佛教寺庙）

1. **进殿三件事**：脱帽、摘墨镜、收手机。
2. **顺时针**：绕佛塔、转经筒、参拜路线,一律顺时针。转经筒用手轻轻拨动即可,不要快速猛转。
3. **"伸掌"而非"指指点点"**：在任何寺庙、面对任何佛像或宗教器物,都应用五指并拢掌心向上的手掌指示,而不是单个手指。这是藏地最基本的宗教礼仪。
4. **门槛不能踩**：寺庙的门槛代表"佛的肩头",每个人都要跨过去,不能踩在上面站。
5. **僧人区域**：未经许可不要进入僧舍区。不要用手触摸僧人的袈裟或法器。
6. **经书和法器**：佛殿内摆放的经书(尤其是用黄布包裹的)和法器(金刚杵、法铃等),未经允许不可触碰。
7. **女性特别提醒**：部分寺庙的某些殿宇(如密宗殿)可能禁止女性进入,请留意门口的藏汉双语说明牌。这不是歧视,而是传统修习仪轨的要求。
8. **拍照前先问**：
   - 如果有僧人:用微笑示意,点头询问,对方同意再拍
   - 信众磕长头:从侧面拍摄,不要站在正前方挡住对方路线
   - 一旦看到"禁止拍照"标志(通常是一个红色圆圈里有一个相机图标),必须收起手机和相机

## 【三】藏民互动礼仪

### 去藏家做客的基本守则

**进门前后：**

1. **进门前的问候**：说一声"贡卡桑"(藏语"您好"),主人会非常高兴。即使不会藏语,微笑和双手合十的问候手势也同样被接纳。
2. **脱鞋入内**：藏式民居客厅铺有卡垫(藏式地毯),需在门口脱鞋。
3. **座位规矩**：藏家客厅通常有主座(靠佛龛方向的长座),留给主人或年长者。客人应坐在两侧或下座。不要一屁股坐到主座上。
4. **双手接物**：主人递茶、递食物时,应用双手接。如果不方便双手,右手接同时左手托右手肘——这是藏族的传统礼节。

### 酥油茶的礼仪（非常重要）

酥油茶是藏族家庭待客最基本的礼节,藏民判断一个游客"懂不懂规矩",第一眼就是看你怎么喝酥油茶：

1. **接碗姿势**：主人倒好酥油茶双手递给你,你应该双手接过。
2. **不要一口喝完**：第一碗不要一口气喝光。呷一小口,主人在你喝完之后立刻会给你续满——这是藏族待客的传统:不能让你的碗空着。不续满反而说明主人不欢迎你(这是极罕见的情况)。
3. **续三次以上**：标准的流程是:喝一点→主人添满→再喝一点→主人再添满。如此重复。如果喝饱了,就**把碗底剩余的茶用手指轻轻泼在地上**,或者**将碗扣在桌上**(意思是"我喝好了")。这样主人就不会再给你倒了。
4. **评价茶**：喝到酥油茶,真诚夸一句"很好喝"(藏语"森杰桑")。即使第一口不太适应酥油的味道,也值得多喝几口——在高海拔地区,酥油茶是缓解高反、补充热量最好的天然饮品。
5. **绝对不要浪费**：不喝可以礼貌婉拒,不要让主人倒了你又不碰。

### 关于摸头

**这是汉族游客最容易犯的大忌。**

1. **禁忌**：**绝对不要摸藏族小孩的头顶**,即使你觉得"这孩子真可爱,摸摸头"。藏族人认为头顶是灵魂居住的地方,摸头顶会压住小孩的福气和运气,甚至会吓走保护神。
2. **替代方式**：喜欢小朋友的话,可以微笑着递一颗糖,或者轻轻拍拍肩膀和手臂。不要摸头。
3. **同样适用于出家人**：不要摸僧人的头顶或袈裟。

### 关于拍照

1. **先问后拍**：在藏区,不要拿着长焦镜头对着藏民的脸就拍。先微笑着指指相机,对方同意(点头或微笑)再拍。
2. **被拒绝时**：如果对方摇头或摆手,笑着说一声"打扰了",放下相机。不要追着拍。
3. **付费摆拍**：八廓街等地有藏民穿着传统服饰供游客合影(通常收费10-20元),这是明确标价的商业行为,可以放心。
4. **磕长头者**：从侧面拍,不要站在对方正前方挡住去路。拍完微微合十表示感谢。
5. **朝圣路上的藏民**：G318、青藏线上磕长头去拉萨的朝圣者,可以拍,但不要停车围观太久打扰他们的行程。拍完可以给一瓶水或一点干粮——这才是藏民之间最受认可的互动方式。

### 称呼与交流

1. **怎么称呼人**：
   - 年长女性：**阿佳**（意为"大姐"）
   - 年长男性：**阿古**（意为"大叔"）
   - 年轻女性：**普姆**（意为"姑娘"）
   - 年轻男性：**普**（意为"小伙子"）
   - 出家人/僧人：**格西拉**（老师/尊者）,或者统称**阿卡**
   - 不懂或不确定：双手合十说一句"扎西德勒"永远不会错

2. **"扎西德勒"的正确使用**：
   - 见面说"扎西德勒",对方会回答"扎西德勒,彭松措巴"(吉祥如意,愿你圆满)。
   - 告别时说"扎西德勒",对方会回答"扎西德勒,德莫"(吉祥如意,一路平安)。
   - 这句祝福在藏区通行无阻,比"你好"更受欢迎。

3. **交流禁忌**：
   - 不主动谈论达赖和西藏政治话题
   - 不追问对方家庭收入、财产等私人问题
   - 不评论当地的宗教习俗"落后""迷信"(可以说"和我们的习惯不太一样,很有意思")
   - 如果遇到当地人在天葬台举行仪式,保持距离、不拍照、不交谈、快速离开

### 购物与交易礼仪

1. **讨价还价规则**：
   - 路边摊和集市可以讨价还价,但保持尊重。开价后你还价,对方接受了,就**必须买下**。随便还价然后不买会被认为"不讲信用",这是在藏区集市上最招人烦的行为。
   - 不买就不要乱还价。

2. **货真价实的提醒**：
   - 虫草、天珠、蜜蜡、老唐卡这些高价物品,如果你不懂行,不建议在路边摊买。超过200元的物品,请去有正规营业执照的商店。
   - 别相信"这个天珠是从喇嘛手里请来的"这类话——这是骗子最常用的套路。

3. **不要随便拿**：
   - 没有问价就拿起来端详,在藏区会被视为"想买"的信号。问价、触摸、询价这条流程要清晰。

### 天葬与丧葬礼仪

1. **绝对不要观看或拍摄**：天葬台是不对外开放的宗教场所。有的天葬台(如直贡梯寺天葬台)在远处可以看到,但**严禁走近、拍照、录像**。
2. **遇到天葬仪式**：如果路上遇到运遗体的车辆或马队,停车让行、保持肃穆。
3. **不要主动提起**：和藏民聊天时不要主动问"你们是不是都天葬""天葬是怎么操作的"——这相当于有人第一次见到你家人就问"你们家老人去世了怎么火化的"一样失礼。
