# 高海拔住宿潜规则 — 供氧供暖、洗澡禁令、水电真相

> 老领队Allen扎西说：你在携程上看到的西藏酒店照片和真实入住体验之间，可能差着一整条青藏铁路。不是藏民不诚实，是高原的客观条件摆在那——有些事你不住进去不会知道。
>
> 这份指南把西藏住宿最真实的底裤扒给你看。

## 一、供氧 —— 可能是骗人的

### 所谓的"酒店供氧"分三种

| 类型 | 描述 | 效果 | 民宿概率 | 连锁酒店概率 |
|:----|------|:----:|:--------:|:-----------:|
| **弥散式供氧** | 整个房间的氧气浓度提高 | 🌟🌟🌟🌟🌟 真有用 | 10% | 50% |
| **鼻吸式供氧** | 床头有个氧气终端，插管子到鼻子里 | 🌟🌟🌟 有用但睡觉不舒服 | 30% | 80% |
| **便携氧气罐** | 前台卖你 ¥30 一罐的氧气罐 | 🌟🌟 应急用可以 | 90% | 100%（卖给你，不是免费） |

### 订酒店时怎么问清楚

在携程/美团上看到"供氧房""供氧酒店"的字样，打电话问前台的时候要确认：

```
❌ 千万别这样问：
"你们有供氧吗？"
→ 前台一定回答 "有的"（不管有没有）

✅ 应该这样问：
"供氧是弥散式的还是鼻吸式的？需要额外收费吗？"
→ 弥散式 = 有用，鼻吸式 = 凑合，需要另外收费 = 不免费

"供氧是24小时的吗？还是需要找前台开？"
→ 有的酒店为了省电，晚上10点后关氧

"供氧额外收费吗？"
→ 有些酒店写着"供氧房"但入住后告诉你¥100/晚
```

**Allen扎西大实话：**
- 拉萨和林芝的连锁供氧酒店（如拉萨香格里拉、林芝工布庄园）的弥散式供氧是真的有用——价格贵但也值得
- ¥200 以下的民宿写着"供氧"的，大概率是前台卖你氧气罐
- 如果你高反不严重，其实不需要供氧——身体适应是一个自然过程
- 如果你高反很严重：直接去自治区人民医院吸医用氧，比住供氧酒店靠谱得多

## 二、供暖 —— 你以为夏天不需要？错！

### 西藏的"夏天"是假夏天

| 城市 | 7月白天 | 7月夜间 | 你真实感受到的 |
|:----|:-------:|:-------:|---------------|
| **拉萨** | 20-25°C | **8-12°C** | 白天热到穿短袖，晚上冷到穿羽绒服 |
| **林芝** | 22-26°C | **12-15°C** | 白天舒服，晚上微凉 |
| **日喀则** | 20-24°C | **8-10°C** | 晚上冷 |
| **珠峰大本营** | 10-15°C | **0-5°C** | 全天都需要厚衣服 |
| **纳木错** | 12-15°C | **-5-0°C** | 晚上冻死人 |
| **阿里** | 18-22°C | **5-8°C** | 昼夜温差极大 |

**夏天住酒店的真实现状：**

```
7-8月进藏，白天28°C，晚上8°C
你订的¥300的酒店 → 空调？不存在的
                         有很多西藏的老酒店根！本！没！装！空！调！
                         因为他们觉得："夏天才十度要什么空调"
你问前台"有没有暖气" → 前台：没有暖气，但是有电热毯
```

**Allen扎西给你三句实在话：**

1. **¥300 以下的酒店/民宿夏天大概率只有电热毯，没有空调和暖气**
2. **¥500 以上的连锁酒店（全季、亚朵等）有空调**，但制冷制热效果都不如内地好
3. **最好的取暖方案：自己带一件抓绒内胆+羽绒服，睡觉开电热毯**

**订房前问前台的话术：**
```
"房间有空调吗？是冷暖空调还是单冷？"
"没有空调的话，有没有电热毯？有几床被子？"
```

## 三、4000 米以上严禁洗澡 —— 这不是建议，是命令

洗澡在平原上是最正常不过的事，但在高原上每一步都是坎。让我把话说清楚：

### 为什么洗澡是高反的第一杀手

| 原因 | 解释 |
|:----|------|
| **血管扩张** | 热水让全身血管扩张，血液流向皮肤→大脑和器官供血减少→高反加剧 |
| **氧气消耗** | 洗澡时呼吸加快，耗氧量增加。在高原上氧气本来就少，你还在加速消耗 |
| **水温变化** | 洗完热水澡→毛孔张开→出来遇到冷空气→血管突然收缩→高血压+头痛 |
| **摔倒风险** | 高海拔下蹲久了站起来会头晕→浴室滑倒→骨折或脑震荡 |
| **脱水** | 热水澡加速身体水分流失→血液变稠→高反更严重 |

### 洗澡铁律（按海拔分级）

| 海拔 | 建议 |
|:----:|:----|
| **<3000m**（林芝、波密） | 可以洗。洗完马上擦干穿衣服，别着凉 |
| **3000-3500m**（拉萨、康定） | 如果身体适应得好 **可以洗**，但：水温不要太高（37-40°C）、时间不超过5分钟、洗完马上穿衣服吹干头发。**进藏前24小时不要洗** |
| **3500-4000m**（拉萨、日喀则） | **建议不洗。** 用湿毛巾擦身+换内衣裤。扛不住了想洗→严格按上面的操作 |
| **>4000m**（理塘、那曲、阿里） | **严禁洗澡！** 没有任何商量余地。这个地方洗澡就是在赌命 |
| **>4500m**（纳木错、珠峰大本营） | **想都不要想。** 这里连呼吸都困难，哪有条件洗澡 |

**Allen扎西亲眼见过的真实案例：**
```
去年一个哥们，从成都飞拉萨，落地第一晚没忍住洗了个澡
→ 洗到一半开始头晕恶心
→ 赶紧擦干出来，躺在床上头痛欲裂
→ 第二天血氧掉到 78%，送去自治区人民医院吸氧+输液
→ 行程耽搁 3 天
本来计划好的林芝珠峰全泡汤，机票改签又花了一千多
就为了洗一个澡。
```

### 不洗澡怎么保持干净

| 问题 | 方案 |
|------|------|
| 头油 | 带一瓶免洗喷雾（碧缇丝之类），¥20-30，喷一喷梳一梳 |
| 身上出汗 | 湿毛巾擦身，换干净内衣裤。西藏干燥，汗干得快 |
| 私处卫生 | 湿厕纸+一次性内裤（强烈推荐！）。一次性内裤穿一条丢一条，省事 |
| 脚臭 | 每天换袜子，湿纸巾擦脚 |

**进藏头 48 小时的标准卫生流程：**
```
早上：起床→用湿毛巾擦脸擦脖子→喷头发免洗喷雾→换干净内衣
晚上：湿毛巾擦全身→换干净内裤袜子→刷牙洗脸→钻被窝
两天后如果身体适应了（不头痛、血氧正常）→ 可以洗一次快速澡
```

**等等——有人说"用湿毛巾擦身不难受吗"？**
难受，但比你洗完澡高反躺在床上吸氧好受一亿倍。

## 四、水电真相：停电停水是常态

### 西藏的供水现状

| 地区 | 供水情况 | Allen扎西备注 |
|:----|---------|---------|
| **拉萨市区** | 24小时有自来水，水压正常 | 水质硬（矿物质多），喝开水或瓶装水 |
| **林芝市区** | 正常 | 林芝水资源丰富 |
| **西藏县城**（如波密、鲁朗、当雄） | 大部分正常，但偶尔停水 | 旺季用水量大，晚上可能水压小 |
| **偏远客栈**（阿里、那曲、珠峰） | **限时供水**！晚上可能没热水 | 很多客栈晚上 8:00-10:00 才烧热水洗澡（虽然你不该洗） |
| **珠峰大本营帐篷** | 基本没有 | 带湿纸巾 |

### 西藏的供电现状

| 地区 | 供电情况 | Allen扎西备注 |
|:----|---------|---------|
| **拉萨市区** | 几乎不停电 | 供电稳定，但夏天雷雨季节可能跳闸 |
| **林芝市区** | 正常 | 稳定 |
| **西藏县城** | 大部分稳定 | 偶尔停电检修 |
| **偏远客栈（阿里）** | **可能限时供电** | 有的客栈晚上 11 点后断电，要么用发电机（很吵） |
| **珠峰大本营帐篷** | 太阳能+发电机 | 晚上供电时间有限 |

**应对方案：**
```
✅ 带一个 20000mAh+ 的充电宝（至少能充 3-4 次手机）
✅ 带一个手电筒或头灯（停电了照明用）
✅ 保温杯灌满热水（停电了至少还有热水喝）
✅ 现金（停电了没法扫码支付）
✅ 别带吹风机（用不了，而且 4000m+ 你也不该洗头）
```

## 五、民宿 vs 酒店怎么选

| 对比项 | 藏式民宿（如桑吉阿佳、诺尔布藏家） | 连锁酒店（如全季、亚朵） |
|:------|:----------------------------------|:------------------------|
| **价格** | ¥80-200/晚，便宜 | ¥300-600/晚 |
| **供氧** | 基本没有供氧，可能有公共供氧 | 有供氧（鼻吸式为主） |
| **暖气** | 电热毯为主，没有空调 | 有空调（但效果一般） |
| **热水** | 限时供应（晚上几个钟头） | 24小时锅炉供水 |
| **体验** | 和藏民一家人住一起，阿佳打酥油茶、跳锅庄 | 标准化，和内地差不多 |
| **WiFi** | 可能有，但网速慢 | 稳定但旺季也慢 |
| **停车** | 院子或路边免费停 | 可能有收费停车场 |
| **钱去哪了** | **直接流进藏民家庭** | 进连锁集团口袋 |

**Allen扎西的住宿选择心法：**

```
如果你高反感较强（头痛、失眠、血氧偏低）
→ 住连锁供氧酒店 ¥300-500/晚
→ 先活着，再谈体验

如果你身体适应良好，想体验真正的西藏
→ 住藏式民宿 ¥80-200/晚
→ 桑吉阿佳民宿的围炉锅庄体验，是五星级酒店给不了的
→ 这笔钱直接帮到藏族家庭

混搭方案：
→ 进藏头 2 晚住供氧酒店适应
→ 后面住藏式民宿体验
→ 最经济也最合理的组合
```

## 六、一句话速查

| 问题 | 答案 |
|------|------|
| 酒店说有供氧 | 打电话问是弥散式还是鼻吸式，24小时还是限时，免费还是收费 |
| 夏天需要暖气吗 | 需要！西藏夏天晚上 8-12°C，很多酒店只有电热毯 |
| 4000m+ 能洗澡吗 | **不能。** 这个高度洗澡是在赌命 |
| 进藏头24小时能洗吗 | **不能。** 管住自己，用湿毛巾擦身+免洗喷雾 |
| 停电了怎么办 | 充电宝+头灯+保温杯热水+现金 |
| 住民宿还是酒店 | 高反重→酒店，适应好→民宿，最佳方案：前2晚酒店后几晚民宿 |
| 一次性内裤带多少 | 在藏天数 × 1.5，穿一条丢一条最省事 |
