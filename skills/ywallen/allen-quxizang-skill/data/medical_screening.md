# 进藏医学自评与病史筛查白皮书

> 老领队Allen扎西说：很多攻略告诉你怎么玩西藏，但没人告诉你"你的身体到底能不能去西藏"。有人到了拉萨第三天活蹦乱跳，有人到了林芝就躺进医院。不是体质问题，是有些病在高原会突然要命。
>
> Allen扎西不是医生，没法给你诊断。但Allen扎西带了15年团，看过三百多次高反，见过五次直升机救援，至少能告诉你——**哪些人是真的不适合来西藏**。

## 一、Allen扎西的进藏医学自评清单

来西藏之前，先打√回答以下 5 个问题。有任意一个 √ 是"是"——**先去挂个号找医生评估，不要自己买机票**：

| 序号 | 问题 | 是 | 否 |
|:----:|------|:---:|:---:|
| 1 | 你是否患有**高血压**（收缩压≥160mmHg 或舒张压≥100mmHg）且**药物控制不稳定**？ | ☐ | ☐ |
| 2 | 你是否患有**心脏病**（冠心病、心力衰竭、心律失常、先天性心脏病未手术）？ | ☐ | ☐ |
| 3 | 你是否患有**慢性阻塞性肺病（COPD）**、**中度以上哮喘**、**肺心病**？ | ☐ | ☐ |
| 4 | 你目前是否**怀孕**？尤其是孕早期（<12周）或孕晚期（>28周）？ | ☐ | ☐ |
| 5 | 3个月内是否有过**脑卒中、心肌梗死、大手术**？ | ☐ | ☐ |

**如果以上 5 个问题你全部选了"否"**——恭喜，你基本是西藏的合格候选者。下面这份白皮书是帮你进一步了解自己的风险和应对方案。

**如果任意一项选了"是"**——读下去之前，先截图发给你的医生，问"大夫，我去西藏海拔3500-5200米待7天，您觉得行吗？"医生说"行"你再往下看。

## 二、哪些病"绝对不建议"去西藏

Allen扎西不吓唬人，但以下情况是真的不建议来。不是"需要注意"，是真的不建议：

| 疾病 | 风险等级 | 为什么 |
|------|:--------:|--------|
| **未控制的重度高血压**（≥180/110） | 🔴 极高 | 高原缺氧使血管收缩，血压可能进一步飙升到脑出血/主动脉夹层的程度 |
| **严重冠心病/心绞痛** | 🔴 极高 | 高原低氧让心脏供氧不足，容易诱发心肌梗死。拉萨海拔3650m对心脏的负荷≈平原背30kg爬10层楼 |
| **心力衰竭（任何阶段）** | 🔴 极高 | 心脏已经泵血无力，高原缺氧只会雪上加霜 |
| **重度COPD（肺功能＜50%预计值）** | 🔴 极高 | 肺功能本来就差，高原氧气含量只有平原的60%——身体根本抢不到足够的氧 |
| **严重哮喘**（日常需吸入激素+长效β₂激动剂控制者） | 🔴 高 | 高原干燥寒冷空气容易诱发哮喘发作，发作起来在高原有生命危险 |
| **肺动脉高压** | 🔴 极高 | 高原缺氧本身就收缩肺动脉，已有肺动脉高压的人可能在高原急性右心衰 |
| **中重度贫血**（血红蛋白＜90g/L） | 🔴 高 | 血液本来就运氧不足，到高原更不够用 |
| **镰状细胞病** | 🔴 极高 | 低氧环境会诱发镰状细胞危象，非常危险 |
| **癫痫未控制**（近半年有发作） | 🔴 高 | 高原缺氧可能降低癫痫发作阈值 |
| **严重糖尿病并发症**（肾衰/视网膜/神经病变） | 🔴 高 | 高原环境变化大，血糖波动难以控制，加上偏远地区医疗条件差 |
| **近期（3个月内）心肌梗死或脑卒中** | 🔴 极高 | 高原缺氧对梗死后心脏/大脑的负担极大，复发风险极高 |
| **近期（1个月内）大手术** | 🔴 高 | 手术未完全恢复，身体处于应激/修复状态，叠加高原缺氧极度不利 |
| **怀孕晚期（28周+）** | 🔴 极高 | 高原低氧影响胎儿供氧，加上偏远地区没有新生儿ICU |
| **怀孕早期（<12周）有先兆流产史** | 🔴 高 | 高原的缺氧环境和体力消耗可能加重流产风险 |

**Allen扎西说：** 如果你属于以上任何一类——哥们，西藏不会跑。身体养好了，以后再来。你跟高原之间不存在"赌一把"，你赌不起。

## 三、哪些病"可以但必须做好准备"

这个表上的病不是禁区，但必须提前准备：

| 疾病 | 风险 | 必须做的准备 |
|------|------|-------------|
| **轻度高血压**（<160/100，药物控制稳定） | 🟡 中 | 3.1 |
| **轻度/中度哮喘**（偶尔发作，吸入剂控制良好） | 🟡 中 | 3.2 |
| **糖尿病**（血糖控制稳定） | 🟢 低 | 3.3 |
| **冠心病/支架术后**（>6个月，无残余缺血） | 🟡 中 | 3.4 |
| **甲状腺疾病**（甲亢/甲减控制稳定） | 🟢 低 | 3.5 |
| **轻中度贫血**（Hb 90-120g/L） | 🟡 中 | 3.6 |
| **抑郁症/焦虑症**（稳定期） | 🟢 低 | 3.7 |
| **慢性肾病**（肾功能正常或轻度下降） | 🟡 中 | 3.8 |
| **怀孕中期**（14-27周，正常妊娠） | 🟡 中 | 3.9 |

### 3.1 高血压患者进藏须知

- **带足平时吃的降压药**，带双倍量（万一行程延长、药丢了还有备份）
- **不要自作主张停用ACEI/ARB类药物**——网上说"高原不要用XXX"都是谣言，听你医生的
- 到拉萨后前24小时**卧床休息**，不要一落地就去逛布达拉宫
- 每天早晚各量一次血压——如果持续>160/100，立刻下撤到低海拔（林芝≈2800m）
- **绝对禁止饮酒！** 酒精+高原+高血压=脑出血风险几何级上升
- **避免剧烈运动、长时间淋浴（浴室蒸汽=相对低氧环境）**

### 3.2 哮喘患者进藏须知

- **务必带足日常控制药物**（吸入性激素+长效β₂激动剂）
- **谨记携带急救药物**（短效β₂激动剂如沙丁胺醇吸入剂）
- 高原空气干燥寒冷，出机场就**戴口罩**（湿润保暖过滤），前48小时不要取下
- 到拉萨后不要开窗吹风——夜间温度骤降会诱发支气管痉挛
- 如果到拉萨24小时内发作需要用到急救药物→**立刻下撤**

### 3.3 糖尿病患者进藏须知

- **血糖监测频率加倍**（高原低氧可能影响胰岛素敏感性，血糖波动增大）
- **带双倍量的胰岛素/降糖药**，独立分装（一份放随身包、一份放行李箱）
- 注意胰岛素**不能托运**——飞机货舱温度可能使胰岛素失活。随身带上飞机
- 高原食欲下降/呕吐/腹泻会导致低血糖风险上升，随身带**糖块/饼干/葡萄糖粉**
- 到拉萨前三天严格控制饮食，不要被藏餐的诱惑击垮血糖控制

### 3.4 心脏支架/术后患者进藏须知

- **必须距离支架/搭桥手术≥6个月**，且复查无残余缺血
- **必须带好既往病历和心电图**，到拉萨后如有需要可直接对比
- 到拉萨后严格限制日常活动——前48小时只做三件事：吃饭、上厕所、躺着
- 备好硝酸甘油/速效救心丸，放在外套内袋里随时可取
- 如果有任何胸闷——**不要扛，不要吸氧观察，直接去西藏自治区人民医院**

### 3.5 甲状腺疾病患者进藏须知

- 甲亢/甲减控制稳定的情况下进藏风险很低
- **带足药物**，按时服用，不要因为时差/行程打乱停药
- 高原气候和饮食变化可能影响甲状腺激素需求——出现明显心慌/乏力/怕冷等变化时，缩短行程下撤

### 3.6 轻中度贫血患者进藏须知

- Hb<110g/L的女性或Hb<120g/L的男性，到拉萨后的高反症状会比常人严重得多
- 出发前可以请医生开具**口服铁剂**，提前2周开始补充
- 到拉萨后**减少活动量**——你可能需要别人2倍的休息时间来适应
- 如果到后24小时血氧饱和度持续<85%——不要硬扛，下撤

### 3.7 抑郁症/焦虑症（稳定期）患者进藏须知

- 高原环境可能加重焦虑（表现为心悸、气促、胸闷——"我是不是高反了"的超价观念）
- **带足日常药物，不要停药**——很多人担心"抗抑郁药在高原会不会有副作用"而自行停药，结果在拉萨出现撤药反应
- 到拉萨前三天保持低预期——你可能会觉得"我怎么不兴奋""好难受"，这是正常的
- 建议找一个有高海拔旅行经验的人陪同——能帮你区分"正常的适应期不适"和"真正的危险信号"
- **严重恐高症者慎重**：甘丹寺60度盘山路、珠峰108拐、色拉寺后山歩道，真的会触发panic attack

### 3.8 慢性肾病患者进藏须知

- 肾功能正常或轻度下降（eGFR≥60）且血压控制良好：风险较低
- 中重度肾衰（eGFR<45）：不建议——脱水+缺氧对残余肾功能的打击不可预测
- 出发前抽血查一次肾功能基线，带好报告

### 3.9 孕妇进藏须知

Allen扎西把最难说的事放在最后。Allen扎西明确建议：**怀孕期间最好不要来西藏——如果你一定要来，只推荐孕中期（14-27周）且正常妊娠。**

- 孕早期（<14周）：不推荐——高原缺氧不确定是否影响早期胎儿发育，加上7天以上的路程可能错过产检关键节点
- 孕中期（14-27周）：可以但要小心——带上产检本，到拉萨后先去医院报备（西藏自治区人民医院妇产科能找到懂普通话的医生），不去海拔>4500m的地方
- 孕晚期（≥28周）：**不建议来**。万一早产，全西藏没有能处理早产儿的新生儿ICU

**Allen扎西说：** 这条写出来Allen扎西知道会被骂"歧视孕妇"。但Allen扎西在冈仁波齐山脚下亲眼见过一个孕妇大出血——那天下着雪，救援直升机飞了三个小时才到。真的，不是歧视，是怕出事。

## 四、药物携带清单与警示

### 4.1 自己带药的基本原则

| 药物类型 | 说明 |
|---------|------|
| **慢性病用药** | 带足行程天数×1.5倍，分两份存放（随身+行李箱） |
| **高原/高反药** | 散利痛/布洛芬（头痛）、乙酰唑胺/醋甲唑胺（预防AMS，需医生开具）、地塞米松（严重AMS，需医生开具） |
| **急救药** | 硝酸甘油（心绞痛）、沙丁胺醇吸入剂（哮喘）、地西泮（惊厥）——视个人病史 |
| **肠胃药** | 黄连素/蒙脱石散（腹泻）、多潘立酮（恶心/呕吐） |
| **感冒药** | 含对乙酰氨基酚的复方感冒药、氨溴索（化痰） |

### 4.2 在西藏买药的三大陷阱

| 陷阱 | 真实情况 | 怎么办 |
|------|---------|--------|
| "藏药治高反，比西药管用" | 部分藏药确实有辅助效果（红景天/灵芝类），但严重高反需要的是氧气、地塞米松和降颅压药物，不是藏药 | 备好西药，到了再买藏药体验可以，但不要替代西药 |
| 药店推荐"最好的高反药" | 通常推荐的是高价保健品的复方制剂（¥100-300/盒），有效成分基本就是对乙酰氨基酚+咖啡因 | 出发前在你们家门口药店买散利痛（¥15/盒），效果一样 |
| 氧气房/氧气枕 | 路边小店卖的氧气枕（¥50-100/个）大多漏气，装不到半小时就没氧了 | 药店买正规罐装氧（¥25-35/罐），或通过携氧/美团外卖正规配送 |

## 五、到了高原后监控旧病的"黄金48小时"

进藏后前48小时是所有旧病最容易恶化的时间段。以下是你必须监控的指标：

| 疾病 | 监控指标 | 危险值 | 行动 |
|------|---------|:------:|------|
| 高血压 | 血压 | ≥160/100持续4小时 | 口服降压药后卧床，2小时不降→下撤 |
| 糖尿病 | 指尖血糖 | 血糖<3.9或>16.7 | 补糖/补胰岛素，不稳定→下撤 |
| 哮喘 | PEF（呼气峰流速） | 降至日常值60%以下 | 使用急救吸入剂，不缓解→下撤 |
| 冠心病 | 胸闷+心电图 | 新发ST段改变或持续胸闷>15分钟 | 含服硝酸甘油，不缓解→120去西藏自治区人民医院 |
| 癫痫 | 发作频率 | 任何一次发作 | 平卧防窒息，发作>5分钟→120 |
| 贫血 | 血氧饱和度+心率 | SpO₂<80%或静息HR>120 | 吸氧2L/min, 不升→下撤 |
| 焦虑/惊恐 | 惊恐发作 | 发作时伴有呼吸性碱中毒（手麻/嘴麻） | 纸袋呼吸（CO₂重复吸入），安定2.5mg口服 |

## 六、Allen扎西的最终建议

**如果你读了这份白皮书还在犹豫"我能不能去"——**

去三甲医院挂一个**呼吸内科**或**高原医学门诊**（华西、协和、301都有高原医学方向），做一次**低氧耐受试验**（模拟海拔4000m的氧浓度下测试你的心肺反应）。⚠️ **全国能做此试验的医院极少，出发前务必电话确认该院是否开展此项检查。** 这个试验的花费（¥300-800）比你买一张去拉萨的机票（¥1500-3000）便宜多了——而且能直接告诉你"你的身体适不适合西藏"。

**Allen扎西最后一句：**

西藏不像三亚普吉岛，不是说走就走的旅行。你买好了机票订好了酒店，结果到了机场发现血压飙到180被劝返——那不是"遗憾"，那是捡了一条命。
