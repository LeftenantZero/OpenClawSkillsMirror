# 运营商红黑榜与离线地图保命准备

> 老领队Allen扎西说：在西藏，你手机没信号的时候比有信号的时候多。这不是 2026 年技术还不够好——是那些雪山垭口和深谷河谷，谁来也没用。
>
> **分清"哪里会没信号"和"没信号了怎么办"，是在西藏手机使用的核心技能。**

**结论：**

```
进藏首选：中国移动 ✅
     └─ 覆盖最广，318沿线大部分垭口有信号
     └─ 阿里/那曲偏远地区只有移动能勉强用
备选：中国电信 ✅
     └─ 拉萨林芝市区和移动差不多
     └─ 但离县城远一点就开始掉队
不推荐：中国联通 ❌
     └─ 出拉萨市区 50 公里基本失联
     └─ 318 大部分路段无服务
```

**Allen扎西的建议：** 如果你平时用联通做主力号，出发前去办一张移动的短期卡或者买个移动流量包当副卡。西藏不是内地，联通在那边的覆盖真的很拉胯。

## 三、离线地图：进藏前必须准备好的东西

**在西藏，靠手机流量导航是不靠谱的。出了县城你可能就没信号了，但路不会因为你没信号就消失。**

### 必须下载的离线地图（出发前在 WiFi 下完成）

| App | 下载内容 | 数据量 | 说明 |
|:----|---------|:-----:|------|
| **高德地图** | 西藏自治区离线地图 | ~500MB | 重点：西藏全境 + 四川省（318川藏线需要四川段） |
| **百度地图** | 同上 | ~500MB | 两个 App 都下，有些地方高德有的百度没有 |
| **奥维互动地图** | 感兴趣的路线叠加谷歌卫星图 | ~1-2GB | **自驾者的终极武器**——能看到卫星图上的路况 |
| **两步路 / 六只脚** | 徒步路线轨迹 | 按需 | 如果要徒步（库拉岗日、冈仁波齐转山等） |

**下载清单：**
```
出发前在 WiFi 下做——
✅ 高德地图：「西藏自治区」离线地图 + 「四川省」离线地图
✅ 百度地图：「西藏自治区」离线地图
✅ 奥维互动地图（自驾者）：318川藏线 + 青藏线 + 阿里大北线 卫星图区域
✅ 微信里的钱转一些到零钱（没信号时也能扫码支付）
✅ 离线藏语翻译包：Google Translate 或者讯飞输入法
```

## 四、没信号的时候怎么活

| 场景 | 怎么做 |
|------|--------|
| **导航没信号** | 高德离线地图会继续工作，GPS 本身不需要网络。**出发前先设置好路线，离线模式照常导航** |
| **想发定位给家人** | 在有信号的时候发一个"我在XX，接下来要穿XX段（约X小时无信号），到了有信号的地方再联系你" |
| **车坏在半路没信号** | 有卫星电话就打卫星电话。没有的话——等过路车帮忙（318车流量大，一般半小时内会有车经过）。阿里大北线可能需要等几个小时甚至一天，备好干粮和水 |
| **人高反了没信号** | 318 上打的 120 在有信号的地方会接通。如果没信号，拦车求助——大货车司机是最靠谱的路救，他们对沿途的医院和修车点最熟 |

## 五、卫星电话：要不要买

| 情况 | 建议 |
|------|------|
| **只去拉萨+林芝** | 不需要。全程有信号或者距离有信号的地方不超过 2 小时车程 |
| **自驾 318/317** | 不需要买。沿途城镇间距不远 |
| **去阿里** | **强烈建议租一台。** 阿里大北线上出了狮泉河到改则、尼玛那一段，四五百公里没有像样的乡镇，车坏了就是等死 |
| **去冈仁波齐转山** | 建议带。转山路上大部分无信号 |
| **徒步墨脱/库拉岗日等** | 必须带。 |

**卫星电话怎么搞：**
- 租：拉萨很多户外店有卫星电话出租，¥30-50/天
- 买：北斗海聊、华为卫星通信终端等，¥2000-5000
- 最便宜的方案：微信上搜"卫星电话租赁"，有商家快递给你

## 六、充电保命指南

| 场景 | 充电方案 |
|------|---------|
| 拉萨/林芝市区酒店 | 正常充电，和内地一样 |
| 川藏线自驾 | **车上备车载充电器**，充手机+充电宝 |
| 阿里/偏远地区 | **可能停电！** 很多客栈晚上会停电或限时供电 |
| 徒步/转山 | 带 20000mAh+ 充电宝两个 |

**充电宝建议：**
- 20000mAh 以上，带两个
- 别买一二百块那种虚标容量的——进藏没电了是真的会出事的
- 带上多头充电线（USB-C + Lightning + Micro-USB），你永远不知道同行的人用什么接口

## 七、一句话总结

```
主力用移动，备选加电信，联通基本当没有
出发前下好离线地图，阿里地区建议租卫星电话
GPS 不需要网络，离线导航照用
进无人区前给家人发个报备：几点进、几点出、预计几点有信号
没信号了别慌——318/317上的大货车司机就是最好的救援队
```
