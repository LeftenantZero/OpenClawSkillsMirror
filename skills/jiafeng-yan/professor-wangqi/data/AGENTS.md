# data

## Purpose
Source PDFs and extracted knowledge cards. This directory contains the raw materials (PDF documents) and the processed outputs (structured JSON knowledge cards) used for vector indexing and retrieval.

## Subdirectories
| Directory | Purpose |
|-----------|---------|
| `01-体质与疾病文章-SCI/` | 13 SCI research papers on constitution-disease relationships |
| `03-王琦老师诊疗经验/` | 25 clinical experience articles from Professor Wang Qi's practice |
| `cards/` | Extracted knowledge cards in JSON format (see `cards/AGENTS.md`) |

## For AI Agents

### Working In This Directory
- Source PDFs should not be modified
- Knowledge cards in `cards/` are generated by `../scripts/extract_knowledge_cards.py`
- Re-run extraction if PDFs are added or modified

### PDF Naming Convention
- SCI papers: Numbered prefix (e.g., `1 Pathogenesis of allergic diseases...pdf`)
- Clinical experience: Chinese titles with author (e.g., `王琦教授治疗过敏性鼻炎经验_李英帅.pdf`)

### Knowledge Card ID Format
- Paper cards: `WQ-SCI-001` to `WQ-SCI-013`
- Experience cards: `WQ-EXP-001` to `WQ-EXP-025`

### Testing Requirements
- Verify all PDFs have corresponding knowledge cards
- Check card content completeness (title, abstract, knowledge_points)
- Validate JSON structure against `../references/knowledge-card-schema.md`
